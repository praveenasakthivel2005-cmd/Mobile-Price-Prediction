# 📱 Mobile Price Prediction using Machine Learning

## 📌 Project Overview

This project predicts the price of a mobile phone based on its specifications using Machine Learning.

The model uses mobile details such as Brand, RAM, Storage, Battery, Camera, and Year to predict the estimated mobile price.

## 🎯 Objective

* Predict mobile phone prices
* Compare different Machine Learning models
* Select the best-performing model
* Understand the relationship between mobile specifications and price

## 📊 Features Used

* Brand
* RAM (GB)
* Storage (GB)
* Battery (mAh)
* Camera (MP)
* Year

**Target:** Mobile Price (INR)

## 🤖 Machine Learning Models

The following models were used:

1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor
4. Gradient Boosting Regressor

The models are compared using:

* MAE
* RMSE
* R² Score

## 📈 Data Visualization

The project includes charts for:

* Average Mobile Price by Brand
* Average Mobile Price by Year
* RAM vs Mobile Price
* Mobile Price Distribution
* Model Comparison
* Actual vs Predicted Price
